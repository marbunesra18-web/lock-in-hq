Block distracting apps

A web app can't close other apps, but your phone can. Set this up once. The Lock In Android app can block them for you.
Blocked during focus
  1. Make a Study FocusSettings → Focus → + → Custom → name it "Study". Allow notifications only from school apps. Everything else goes silent while it's on.
  2. Hard-block with Screen TimeSettings → Screen Time → App Limits → Add Limit → pick Social and Entertainment → set 1 min → turn on "Block at End of Limit". Ask a parent to set the Screen Time passcode so you can't skip it.
  3. Send TikTok back hereShortcuts app → Automation → + → App → choose TikTok and Instagram → "Is Opened" → Run Immediately → add "Open URLs" with this app's link (copy it from Share). Opening TikTok drops you into Lock In instead.
  1. Turn on Focus modeSettings → Digital Wellbeing → Focus mode → select TikTok, Instagram, YouTube and games → Turn on now. Those apps stay paused until you turn it off. Add a schedule for study hours.
  2. Set app timersDigital Wellbeing → Dashboard → tap an app → App timer → e.g. 30 min a day. When time's up, the app is paused until midnight.
  3. Bedtime modeDigital Wellbeing → Bedtime mode makes the screen grayscale and silent at night, so scrolling gets boring.

Menu names vary a little by phone brand and OS version.
